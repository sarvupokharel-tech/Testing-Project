# Python Starter Examples

Files:
- `hello.py`       - interactive greeting
- `variables.py`   - basic types and collections
- `control_flow.py`- conditionals and loops
- `functions.py`   - functions and return values
- `file_io.py`     - reading and writing files
- `classes.py`     - simple class example

Run instructions:
1. Install Python 3.10+ from https://python.org (or use your package manager).
2. (Optional) Create a virtual environment:
   ```
   python -m venv .venv
   # Windows PowerShell
   .venv\Scripts\Activate.ps1
   # macOS/Linux
   source .venv/bin/activate
   ```
3. Run a file:
   ```
   python hello.py
   python variables.py
   ```

Notes for beginners:
- Edit files in a text editor, save, then run with `python <filename>.py`.
- Ask me to expand any example into exercises or to create additional files.
